# finance-query

finance-query, the Rust market-data library, called in-process from Python

Python bindings for the `finance_query` crate, generated by [soothfast](https://github.com/Verdenroz/soothfast). Do not edit by hand: run `cargo soothfast bind gen` instead.

## Install

```bash
pip install finance-query
```

The wheel ships `py.typed` and a stub, so editors and type checkers see the surface.

## Use

```python
import finance_query
```

## Classes

### `Interval`

Chart intervals


### `TimeRange`

Time ranges for chart data


### `Candle`

A single OHLCV candle/bar


### `Chart`

Fully typed chart data


### `Dividend`

Public dividend data


### `ChartMeta`

Metadata for chart data


### `News`

A news article


### `Provider`

Typed identifier for a financial data provider.


### `Ticker`

The primary entry point for querying financial data for a single symbol.

- `chart`
- `chart_range`
- `dividends`
- `news`
- `symbol`
- `new`
