Economic Indicators#

abstract · Cargo Docs

docs.rs/finance-query — EconomicIndicator

info · Feature flag required

The economic domain requires at least one provider feature. FRED is the primary recommended provider:

The EconomicIndicator domain handle fetches macro-economic time series data. It is backed by FRED (Federal Reserve Economic Data), with optional Alpha Vantage and Polygon fallbacks, and is keyed by a series ID string.

Getting a Handle#

Create an EconomicIndicator handle from a Providers instance by routing the ECONOMIC capability to FRED, then call .series() to fetch the data:

The series ID is a FRED series identifier such as "GDP", "FEDFUNDS", or "CPIAUCSL". See the FRED series catalog for the full list of 800k+ available series.

note · FRED API Key

FRED requires an API key. Initialise it once before building your Providers instance:

See FRED Provider Reference for setup details.

  • Deserializing a full FRED series response (fred::series → MacroSeries) completes in well under half a millisecond.

EconomicSeries Fields#

The returned EconomicSeries value contains:

FieldTypeDescription
series_idStringSeries identifier (e.g., "GDP", "FEDFUNDS")
titleOption<String>Human-readable series title
unitsOption<String>Unit of measurement (e.g., "Billions of Dollars", "Percent")
frequencyOption<String>Reporting frequency (e.g., "Annual", "Monthly")
observationsVec<MacroObservation>Chronologically ordered observations

Each MacroObservation has:

FieldTypeDescription
dateStringObservation date as YYYY-MM-DD
valueOption<f64>Observation value; None when FRED reports a missing value

Both tables are backed by a compiled, real value — EconomicSeries and MacroObservation are #[non_exhaustive] and have no public constructor, but both derive Deserialize, so a fixture value can be built from outside the crate with serde_json::from_value:
