Data Storage#

The CLI stores alerts and watchlists in:

  • Linux/macOS: ~/.local/share/fq/
  • Windows: %APPDATA%\fq\

EDGAR email configuration is stored in:

  • Linux/macOS: ~/.config/fq/config.json
  • Windows: %APPDATA%\fq\config.json
